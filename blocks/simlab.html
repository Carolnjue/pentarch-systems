every lab

More than an animation. A complete lesson.

Each lab pairs a live simulation with the theory behind it, so students can test what they read and read about what they see.

  • {{icon:play}}

    Live simulation

    Drag, switch and adjust, and every number on screen comes from the same equations as the lecture notes.

  • {{icon:book}}

    Theory and worked examples

    The real equations, explained step by step, with worked examples beside the model.

  • {{icon:star}}

    Challenges and quizzes

    Hands-on scenarios to solve and a quiz at the end, so students can check their own understanding.

  • {{icon:spark}}

    Demos and guided tours

    A short demo and a guided tour show first-time users what to try.

  • {{icon:monitor}}

    Present mode

    Lecturers project any lab in class and run it live while they teach.

  • {{icon:phone}}

    Any device, no install

    Runs in the browser on laptops, tablets and phones, with nothing to download or set up.
