What you can do on the page

Live Edit works on ordinary HTML, so it adapts to each design instead of forcing a template.

  • {{icon:pen}}

    Click any text to type

    Headings, paragraphs, lists and buttons. What you see is what visitors get, with the site's own fonts and spacing.

  • {{icon:monitor}}

    Click a picture to replace it

    Choose a new image from the WordPress Media Library or upload one. Alt text is edited in the same place.

  • {{icon:web}}

    Change where links go

    Click a link or button to change its address. Links to pages that move are repaired automatically.

  • {{icon:layers}}

    Duplicate, move or delete

    Hover a repeated item, such as a service card or a question, to copy it, move it or remove it.

  • {{icon:clock}}

    A revision for every save

    Every save is kept. Compare and restore an earlier version if something goes wrong.

  • {{icon:layers}}

    Site-wide header and footer

    Edit the header or footer once and it changes on every page.

  • {{icon:code}}

    Hand-coded designs, imported

    We write each page in HTML, CSS and JavaScript. Live Edit imports it as an editable block, so design freedom stays.

  • {{icon:cog}}

    Shortcodes inside designs

    Forms, course lists and other dynamic parts sit inside the design and keep working while you edit around them.

    Questions about Live Edit

    Do I need to know code?{{icon:chev}}

    No. You edit by clicking on the page. Code stays with us, for when you want a new section or a redesign.

    Can I break the design?{{icon:chev}}

    Live Edit only changes words, pictures, links and repeated items, so the layout stays as designed. If something looks wrong, restore an earlier revision.

    Can several people edit?{{icon:chev}}

    Yes. Anyone with an editor account on your WordPress site can use Live Edit. Each save records who made it.

    Is Live Edit sold separately?{{icon:chev}}

    Live Edit comes with every website we build. Ask us if you would like it on an existing WordPress site.

    What happens to forms and dynamic parts?{{icon:chev}}

    They are placed as shortcodes inside the design and keep working while you edit the text around them.
